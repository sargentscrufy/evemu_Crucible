# Eliminate a Pirate Nuisance, Level 1 (Guristas)

**Agent / Corp / Location**: Spacelane Patrol / Caldari Navy-linked security agents (high-sec Caldari intro). Deadspace.

**Briefing / Story**: Eliminate small Guristas pirate nuisance group threatening area. Standard low-level security sweep.

**Objectives**: Destroy the pirate ships in the pocket.

**Encounters** (Single deadspace pocket; instant aggro on warp-in; minimal 2-ship group + structure).

#### Single Pocket (45km out)
Instant aggro on warp in.

**Group**:
- 1x Pithi Arrogator
- 1x Pithi Imputor

**Structures**:
- Low Tech Structure (drops various ammo + some Carbon / 10 units)

**Rewards**: Basic L1 ISK, small loot/ammo from structure.

**Strategy / Approach Loops**: Instant aggro — engage immediately. Very easy for rookie frigate (Kestrel/Merlin era reports; super easy DR). No jamming. Kin/Therm damage.

**Era Notes / Caldari Flavor**: Entry-level anti-Guristas security mission. Teaches basic aggro and structure looting. Often first or early security mission offered by Caldari agents.
