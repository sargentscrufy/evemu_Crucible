# The Blockade, Level 3 (Guristas)

**Agent / Corp / Location**: Spacelane Patrol / Caldari Navy agents (high-sec Caldari).

**Briefing / Story**: The Guristas have set up a blockade; clear them out.

**Objectives**: Destroy all Guristas forces.

**Encounters** (Deadspace w/o gate; no accel gate; waves spawn at range; first trigger is the destroyer - easy to one-shot accidentally; random highest-bounty BC is trigger in multi-BC waves; jamming in later waves. Bring kinetic/thermal tank + invuln recommended for BC.)

#### Initial
- 1x Stasis Tower
- 1x Destroyer (Pithior Renegade) **TRIGGER**
- 4x Elite Cruiser (Dire Pithum Abolisher/Eraser/Mortifier)
- 4x Battlecruiser (Pithatis Enforcer/Exectuor)

#### First Wave (50-80km from beacon)
- 1-2x Frigate (Pithi Plunderer/Wrecker)
- 5-6x Destroyer (Pithior Anarchist/Nihilist/Renegade/Supremacist/Terrorist)
- 8-9x Battlecruiser (Pithatis Assassin/Assaulter/Enforcer/Executor) **Highest Bounty TRIGGER**

#### Second Wave (100-130km from beacon)
- 4x Destroyer (Pithior Anarchist/Nihilist/Renegade/Supremacist)
- 2x Elite Cruiser (Dire Pithum Mortifier)
- 6-7x Battlecruiser (Pithatis Assassin/Death Dealer/Enforcer/Executor) **Highest Bounty TRIGGER**

#### Third Wave
- 3-4x Elite Frigate (Dire Pithi Plunderer/Wrecker)
- 2-3x Cruiser (Pithum Abolisher/Eraser)
- 5-8x Battlecruiser (Pithatis Assassin/Assaulter/Enforcer) **Highest Bounty TRIGGER**

#### Fourth Wave (15-30km from beacon)
- 4x Elite Frigate (Dire Pithi Despoiler/Saboteur) **JAMMING**
- 5x Battlecruiser (Pithatis Death Dealer/Revolter) **Completes Mission**

**Blitz**: Kill every trigger, then the last 5 BC on fourth wave. Requires good tank + DPS.

**Rewards**: Loot ~3.1M, salvage ~1.5M, bounties ~6M (era examples).

**Strategy / Approach Loops**: Prioritize triggers (show info for bounty to identify random highest). Kill webs/jams early. Position for ranges. Full clear or blitz per fit.

**Era Notes / Caldari Flavor**: Common L3 Guristas blockade for Caldari agents. No equivalent L4 Guristas version per sources (use Extravaganza instead).
